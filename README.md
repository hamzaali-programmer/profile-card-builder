# Profile Card Builder

A frontend task built as part of a technical interview. Users can enter profile details and generate a live card preview.

## How to Run

Open `index.html` in a browser.

For the React part, open `react/ProfileCard.jsx` in a React environment such as Vite or StackBlitz.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React

## Time Taken

~60 minutes
